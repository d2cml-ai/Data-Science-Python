# Spanish labels

All user-facing text lives in `app/labels.py`. Keep it plain, short and in neutral Peruvian Spanish.

| Concept | Label |
| --- | --- |
| Buy / rent | Comprar / Alquilar |
| Buying wins / renting wins | Comprar gana / Alquilar gana |
| Down payment | Cuota inicial |
| Mortgage rate | Tasa hipotecaria (TEA) |
| Monthly payment | Cuota mensual |
| Building fee | Mantenimiento |
| Property tax | Impuesto predial |
| Opportunity cost | Costo de oportunidad |
| Fixed-term deposit | Depósito a plazo |
| Break-even | Punto de equilibrio |
| Asking price | Precio pedido (not "precio de venta") |
| Real terms | En términos reales (descontando inflación) |
| Needs your input | necesita tu dato |
| Low confidence | baja confianza: pocos avisos |
| Synthetic data | DATOS SINTÉTICOS de prueba |

Disclaimer (from `housing_lima.DISCLAIMER_ES`): "Uso educativo. Esta herramienta compara escenarios construidos
con información pública, fechada, y supuestos explícitos. No es asesoría financiera, tributaria ni de inversión
personalizada."

Numbers: soles as `S/ 350,000`; rates as `8.50%`.
